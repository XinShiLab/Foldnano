# Apply `glass-paper` to floating surfaces

The project has ONE shared frosted-surface design token, `glass-paper`, defined in
`src/app.css` as a Tailwind v4 `@utility` driven by `--glass-*` CSS variables
(`--glass-tint`, `--glass-blur`, `--glass-saturate`, `--glass-edge`, `--glass-highlight`,
`--glass-shadow`) in `:root` / `.dark`.

Floating surfaces (`src/lib/components/ui/**/*-content.svelte` and similar) should wear this
look via the `glass-paper` class — **not** an inline frosted-glass fragment. The
`shadcn-svelte` CLI regenerates these files with its own inline fragment
(`bg-popover/70 … before:backdrop-blur-2xl before:backdrop-saturate-150 ring-1 ring-foreground/10`),
which overwrites our edits. This skill restores `glass-paper`.

## Steps

1. **Do not touch `src/app.css`.** The `glass-paper` utility and `--glass-*` tokens are the
   source of truth and are not regenerated by shadcn. If `@utility glass-paper` is somehow
   missing from `src/app.css`, stop and report — re-creating it is a separate decision.

2. **Find the surfaces that need converting.** The inline frosted fragment always contains a
   backdrop-blur, so grep for the signature:

   ```bash
   rg -l "before:backdrop-blur" src/lib/components/ui
   ```

   Each hit is a floating surface still using the inline fragment. (Files already using
   `glass-paper` won't match — this is idempotent. New surfaces shadcn adds later, e.g.
   `popover`, `menubar`, `hover-card`, are caught automatically.)

3. **For each matched file, edit its `cn(...)` class string:** prepend `glass-paper` and
   **remove** the inline fragment tokens it replaces:
   - `bg-popover/NN` (translucent tint — any number, e.g. `/70`)
   - `shadow-md` or `shadow-lg` (elevation)
   - `ring-1 ring-foreground/10` (edge ring) — OR a standalone `border` token used as the
     surface edge (e.g. `context-menu-sub-content`)
   - the entire contiguous before-pseudo run:
     `before:pointer-events-none before:absolute before:inset-0 before:-z-1 before:rounded-[inherit] before:backdrop-blur-* before:backdrop-saturate-*`

   **Keep everything else** — this is critical, only the look changes, not behavior:
   `text-popover-foreground`, `rounded-none`/`rounded-*`, `relative`, `isolate`, `z-50`,
   `min-w-*`, `w-*`, `overflow-x-hidden overflow-y-auto`, `animate-none!`, `outline-none`,
   `duration-100`, the `data-[side=…]:slide-in-*` animations, the `data-open/closed:*`
   animations, and all `**:data-[slot…]` / `**:data-[variant=destructive]…` item, hover, and
   destructive-state styles.

   `glass-paper` itself provides: the translucent-white background, the `backdrop-filter` blur
   (via its `::before`), the edge hairline, the drop shadow, and the inner highlight — so the
   removed tokens are redundant once it's added.

   Example (`select-content.svelte`):
   - before: `… rounded-none bg-popover/70 text-popover-foreground shadow-md ring-1 ring-foreground/10 duration-100 before:pointer-events-none before:absolute before:inset-0 before:-z-1 before:rounded-[inherit] before:backdrop-blur-2xl before:backdrop-saturate-150 data-[side=…`
   - after: `glass-paper … rounded-none text-popover-foreground duration-100 data-[side=…`

4. **Format + verify:**

   ```bash
   pnpm format    # tailwind class-sorter will reorder the trimmed strings
   pnpm check     # must report 0 ERRORS (pre-existing warnings are fine)
   pnpm lint      # prettier + eslint clean
   ```

5. **Report** which files were converted (and note any that were skipped because they already
   had `glass-paper`).

## Reference: currently-managed surfaces

As of the initial rollout these 5 files used the inline fragment and were converted. Use the
grep in step 2 as the real source — this list can go stale if shadcn adds/removes components:

- `src/lib/components/ui/dropdown-menu/dropdown-menu-content.svelte`
- `src/lib/components/ui/dropdown-menu/dropdown-menu-sub-content.svelte`
- `src/lib/components/ui/context-menu/context-menu-content.svelte`
- `src/lib/components/ui/context-menu/context-menu-sub-content.svelte`
- `src/lib/components/ui/select/select-content.svelte`

## Out of scope

- `dialog` (intentionally an opaque modal surface) and `tooltip` (inverse `bg-foreground`) do
  **not** use `glass-paper`. Don't convert them. Neither contains `before:backdrop-blur`, so the
  grep won't surface them anyway.
- Item/row elements (menu items, separators) — only the popover _surface_ gets `glass-paper`.
